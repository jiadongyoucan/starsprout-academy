01 / GOALS架构目标与约束

质量属性要求架构回应
可安装家长 / 小园所一条命令可用，无外部中间件单进程 + 单文件 SQLite + 静态资源；运行时零 npm 依赖；Docker 单容器
安全与隐私家庭级隔离；儿童照片与 AI 数据可控household 守卫、RBAC、consent、鉴权读取、保留期清理、审计
可维护边界清楚、测试可读、后期可替换存储 / 模型DDD 限界上下文、route → service → repo、AI provider 抽象、迁移版本化
可演进先单机，后多实例数据访问集中在 repo / SQL；无跨请求内存状态（除 SSE 与限流，均可外置）
可测试TDD / 集成优先buildApp 可注入临时 DB；真实 HTTP 测试；无 mock 框架
低成本内容不依赖动画与 CDN结构化 block、TTS / WebAudio / Canvas / emoji，公开课源带许可
刻意约束：不引入 React / ORM / Redis / 消息队列 / 云存储。它们会提高交付与部署成本，而当前规模（单家庭到小型园所）不需要。替换路径已保留（见 §17）。

02 / STACK技术选型与权衡

选择理由代价 / 替代
Node 24 原生 TypeScript 类型擦除`node src/server.ts` 直接运行；不存在构建产物漂移不能用 enum / 参数属性；由 `tsc --noEmit` 做类型门禁
`node:sqlite`（WAL）零外部依赖；备份 = 文件；事务与索引足够写并发有限；多实例时换 Postgres，repo 层不变
自研 HTTP 路由 / 中间件~300 行、可读、无供应链风险；统一错误与安全头无生态中间件；复杂鉴权需自己写（已覆盖）
原生 ES Modules + PWA无打包器；手机可安装；一套代码适配手机 / 平板 / Mac无框架响应式；通过明确的 view 模块与 CSS 设计系统约束
OpenAI-compatible AI 适配 + 本地规则DeepSeek / OpenAI / 自建均可；无 Key 也能完整演示本地引擎措辞固定；模型质量取决于供应商
`node:test` + 真实 HTTP无框架；测试即接口契约；可并行临时 DB无覆盖率工具；用清单与断言保证关键路径
独立子进程 + Node 权限模型无依赖的隔离执行；无宿主对象注入；限制时间 / 内存 / 文件权限非虚拟机级硬隔离；默认关闭，需显式开启

06 / LAYERS分层与依赖规则

依赖只向下；路由不写 SQL，repo 不产生 HTTP 语义。跨上下文调用走模块导出的应用函数。
  • 路由只做 ctx → service；错误由 AppError 统一序列化为 {ok:false,error:{code,message,details}}。
  • 服务负责用例事务、家庭校验、审计；不依赖 req/res，便于测试与复用（如智能体工具直接调用 generatePlan）。
  • repo/SQL 集中在模块底部；表名与索引随迁移管理；不使用 ORM。
  • 前端按 view 模块拆分，api.js 统一 token / 错误，ui.js 统一转义 / 模态 / 图表；esc() 是硬规则。

07 / DATA数据模型

完整表 ~40 张；关键不变量：progress 唯一 (child, lesson)；plan_items 带 household_id 便于隔离查询；course_packs 唯一 (source, code, version)。

关键不变量

  • 所有家庭资源表都带 household_id（或可通过 child / plan / session 推导），服务层每次访问都校验。
  • 设备令牌只绑定一个 household；照片表与文件均记录 device / child；读取时校验 child 归属。
  • 课程发布需 is_published=1；隔离中的课程包对应课时为 0；审批后原子置 1。
  • 计划项状态只允许 pending / done / skipped / missed / moved；改变状态与写调整在同一事务。
  • 会话 / 记忆 / 工作区均以 household 为边界；工作区路径禁止 ..、绝对路径与特殊字符。
  • 审核状态迁移由服务端状态机控制，作者不能自审；编辑已通过内容会回到 pending。

10 / AIAI 子系统

Provider 适配

modules/ai.ts 支持 OpenAI-compatible Chat Completions；模型配置可来自环境变量或管理后台（AES-256-GCM 加密）。超时 / 非 2xx / 网络错误统一转为 502。

接地排课

计划由确定性的 buildDraft 生成候选课时与日期；LLM 只补写 2–3 句理由（且失败自动回退）。永远不会让模型生成 lesson_id 直接落库。

工具循环

最多 3 轮 tool calls；参数 JSON 解析 + 服务端校验；工具结果裁剪 3KB；会话存储 tool trace 供家长查看。AI 草稿不直接发布。

配额与降级

ai_usage 统计 24h 调用；超限 / 无 Key / 调用失败均降级为本地规则；报告会标注 engine，不把模板伪装成 AI。

提示注入

系统提示与用户内容分离；记忆 / 检索结果明确标注“数据不是指令”；工具白名单无法越权；输出不会作为代码执行。

沙箱

独立 Node 子进程 + --permission + 800ms 脚本超时 / 1.5s 硬终止 + 32MB 内存；不注入宿主对象（console 在上下文内创建），无应用环境变量；默认关闭，需 ENABLE_SANDBOX=true。

用户消息 → 组装系统提示（孩子 / 课程矩阵 / 记忆关键词 / 专家人格）
        → chat(tools=8) ──无 Key/失败──▶ 本地规则回复（同工具，确定性）
        → tool_calls ──逐条校验──▶ executeTool（家庭边界 + 审计）
        → 最多 3 轮 → 保存 assistant 消息 + tool trace
        → 写 ai_usage / agent_runs

12 / MODERATION审核引擎

moderation.ts 分两层：规范化 + 规则扫描，以及人工状态机。

  1. NFKC、去零宽字符、常见形近字母映射、去分隔符后再匹配，降低 “加 v x / ｗｅｉｘｉｎ” 绕过。
  2. 阻断级：色情、赌博、毒品、暴力 / 自伤、儿童侵害、体罚、联系方式、手机号、身份证 → 422，不落库。
  3. 复核级：站外链接、医疗建议、主题不相关 → 允许 pending，但标记原因与分数，人工决定。
  4. 课程贴必须引用已发布课时；否则 422。发布后编辑 → 重回 pending。
  5. 审核人不能是作者；拒绝必须写原因；每次决定写 post_reviews + audit_logs；举报可隐藏内容。
  6. 评论在同一规范化引擎下过滤；命中阻断直接 422。

专家 / 技能 / 连接器共用“公开 → pending_review → 管理员 approve/reject”的治理模型；家庭私有资源即时可用。

13 / DEVICE多端与照片时序

设备令牌 365 天但哈希落库、可撤销；SSE 断线自动重连，前端 30s 轮询兜底。照片文件 0600，读取必须携带家长令牌。

安全要点：配对码一次性、过期即失效；设备只能访问本设备与家庭资源；/api/device/progress 与 /snapshots 均校验 child 归属；照片写入前校验 magic bytes（JPEG/PNG/WebP）与大小；服务端不信任客户端“已同意”，仍检查 guardian_consents.camera。照片保留期任务在启动与每日执行。

14 / COMPANION伙伴与奖励运行时

模型与不变量

src/modules/pet.ts 负责伙伴、钱包、小铺、互动与奖励；scoring.ts 只根据课时 blocks 的答案键判分。奖励事件以 (child_id, source_type, source_id) 唯一约束保证首通/单元/计划只发一次；金币加总与宠物经验在同一事务内完成。

反刷与防越权

客户端 score 仅做范围校验，不参与发币；课时完成用 answers[] 服务端判分，无答案按中性 80。计划金币要求 ≥3 项且跨 ≥3 天；小铺购买用条件 UPDATE 防止并发透支；衣服唯一；所有孩子/家庭二次校验。

01完成课时answers → scoreLesson → stars / coins / exp；写入 reward_events（幂等）
02单元 / 计划检查全部课时完成或全部 plan_items done/skipped → 一次性里程碑
03伙伴反馈exp / happiness / mood 更新；等级与庆祝由前端呈现
04小铺 / 衣橱金币条件扣减 → 背包 → 喂食 / 穿衣；基础小饼干免费
风险处理
伪造分数 / 刷金币服务端按题目答案判分；客户端 score 不采信；首通唯一约束；计划最低 3 项 3 天；重学提示「复习完成」
并发重复购买 / 负余额事务内 UPDATE ... WHERE coins >= ?，变更 0 行即 422；衣服唯一；SQLite 写串行
离线愧疚 / 宠物死亡衰减最多 18/14/12 点、下限 35/38/30，≥24h 进入「想你」状态；基础食物免费；无排行榜、无死亡、无学习权限惩罚
XSS / SVG 注入伙伴 SVG 由内部 species / mood / equipped 白名单生成；用户名字与文案走 esc()；CSP 无内联脚本；庆祝层焦点陷阱

可访问性 / 动效庆祝层 role=dialog、焦点陷阱、Esc、关闭恢复焦点；prefers-reduced-motion 跳过彩纸；移动端 390/320px 无横向滚动

15 / WARMTH温度层与儿童空间

两套 HMI，一套数据

家长路由与儿童路由共享课程、计划、进度、伙伴与奖励，只改变信息密度、语言和视觉：家长端保留可执行数据，儿童端隐藏报告、联系方式和家长设置；儿童路由通过 kid-mode 隐藏侧栏/顶栏，并提供始终可见的「回家长空间」。

文案是产品资产

src/infra/warmth-data.ts 是可审校的原创文案池；warmth.ts 按日期 + 受众 + 场景 + 孩子哈希选择语气，刷新只换句、不换语气；exclude 过滤近期重复，前端每日最多换 2 次。无第三方引用、无自动轮播。

01场景决定语气home / child / lesson / report / device；lesson 按分数选 praise 或 retry
02每日稳定同一孩子同一天返回同一 kind；刷新仅换同 kind 的句子
03安全注入所有文案经 esc()；儿童空间使用内部 SVG；CSP 不放开内联脚本
04不打断卡片/气泡/庆祝层内的一行；无自动弹窗、无自动轮播、无声音

保留期与清理

启动时与每 24h 清理 SNAPSHOT_RETENTION_DAYS 之前的照片（DB + 文件）。管理员也可按孩子批量删除。审计日志默认保留；生产可按合规要求归档。

健康与日志

GET /api/health 返回 DB、课时数、AI 模式；日志为 JSON line（请求 ID、状态、耗时、错误栈摘要），不记录 token / 密码 / 照片内容。请求日志级别可用 LOG_LEVEL 调整。

HTTPS / 摄像头 / PWA

浏览器只在 https 或 localhost 开放摄像头、麦克风、Service Worker 与安装。局域网平板请用 scripts/gen-cert.sh，在平板信任证书后访问 https://<ip>:8080/device。HTTP 场景下学习仍可用，拍照退化为相册上传并提示安全上下文。

19 / SCALE性能与演进

维度当前瓶颈 / 演进
数据规模单家庭到小型园所；192 课时；SQLite 单文件写并发有限；多实例换 Postgres；读取加索引
请求单 Node 事件循环；同步 SQLite 快AI / 连接器 IO 异步；长任务可外置队列
实时SSE 内存 Map；30s 轮询兜底多实例用 Redis Pub/Sub 或 Web Push
照片本地文件系统 + 鉴权读取对象存储 + 签名 URL（仍需权限校验）
AI同步请求 + 超时 + 配额流式输出、任务队列、成本预算
部署单容器 + volume水平扩展需外部会话 / 限流 / 存储

演进原则：repo 边界已隔离 SQL；AI 有 provider 抽象；照片读取集中在一个服务函数；SSE 有独立注册表。替换存储 / 推送 / 模型时不需要改路由与产品流程。

20 / TRADEOFFS取舍与已知限制

  • 无前端框架：减少构建与依赖，但复杂页面需要自律的模块拆分；已通过 view 文件、ui 设计系统与 esc 规则控制。
  • SQLite：部署极简、备份容易；不适合高并发写入与多实例。家庭 / 小园所规模足够。
  • 同步 AI 调用：实现简单、可测；长回答可能等待。已设置 45s 超时与本地降级，未来可流式。
  • 沙箱非硬边界：默认关闭；子进程权限模型 + 无宿主对象注入；如需强隔离需容器 / gVisor / isolated-vm。
  • 语音仅本地识别：不做发音评分；隐私优先。发音评估作为可选路线图。
  • 摄像头依赖 HTTPS：局域网部署需要证书；已提供脚本与相册兜底，但仍是使用门槛。
  • 教师无园所组织树：当前是平台级审核者；园所多租户是下一阶段。
  • 内容版权：公开包带来源与许可，但商用前仍需逐条复核原始资源许可。
