08已知边界与未覆盖项

  • 摄像头真实采集需 HTTPS / localhost 与设备授权；自动化环境以相册上传 / 模拟文件代替摄像头硬件。
  • 未做视觉回归基线；当前通过 人工截图与人工检查验证关键页面。
  • 未接入真实 LLM 的端到端测试（避免外部依赖）；用本地规则路径覆盖同一业务流程，AI 适配器有超时 / 降级 / 解析逻辑。
  • 未覆盖极端并发 / 压测；SQLite 单实例的容量边界已在架构文档说明。
  • 园所组织树、Web Push、发音评分、支付属于路线图，不在本次范围。
结论：核心业务与安全负向路径均有自动化证据，关键多端流程通过浏览器实测。验收提出的演示双开关 P1 已关闭，最终测试 90/90。剩余边界均已声明，不阻塞当前单家庭 / 小园所版本交付。
