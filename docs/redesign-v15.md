# v1.5 体验重构 · 创作中心 / 3D 伙伴 / 界面减法

## 问题诊断
- 导航有「儿童空间」「我的伙伴」「智能体」多个交叉入口；顶栏还有重复的钱包/伙伴 chip。
- 首页卡片过多、解释性 hint 过多、信息层级平均；家长找不到「现在最该做的一件事」。
- 伙伴页是 2D SVG + 文字气泡；喂食/摸摸只改变数字和一句文案，缺少真正动作反馈。
- 智能体页面信息密度高，名称偏技术，家长不知道它是「创作」的地方。

## 设计原则
1. **一个主行动**：每个页面只保留一个最明显的下一步；其余降级为次级操作或 hover 解释。
2. **少解释，多控件**：删除重复 hint；必要说明用 `?` + hover/点击 tooltip；标题自解释。
3. **家长效率 / 儿童游戏感**：家长端冷静、留白、清晰；儿童/伙伴端有角色、动作、场景。
4. **真正 3D 的伙伴**：Three.js 本地 vendor，程序化低多边形伙伴 + 房间；喂食/摸摸/玩耍/睡觉有动作、表情、粒子反馈；可旋转视角。
5. **导航收敛**：一级导航 7 项；创作中心取代智能体；儿童空间从侧栏移除，改为首页/伙伴页的明确按钮；顶栏只保留孩子切换、通知、头像。
6. **一致性**：14/16px 字阶、20px 间距、24px 圆角、单一珊瑚强调色；去掉倾斜卡片、过多渐变和装饰。

## 信息架构
- 工作台：首页 / 创作中心 / 学习计划
- 成长：课程 / 伙伴 / 社区
- 家庭：多端 / 账户（管理员多一个后台）
- 儿童空间入口：首页 hero 的「去儿童空间」+ 伙伴页「儿童模式」；不再占一级导航。
- 顶栏：孩子切换、通知、头像；钱包/心情移入侧栏伙伴卡或页面内。

## 3D 伙伴方案
- `src/web/js/vendor/three.module.js`（MIT，本地引入，无 CDN）。
- `pet3d.js`：程序化生成兔/狐/龙；身体、耳朵、眼睛、嘴、四肢、尾巴、配饰；Canvas + WebGL。
- 状态表情：happy/excited/hungry/sleepy/missing；眼睛/嘴/眉毛/身体姿态随状态变化。
- 动作：
  - 喂食：食物飞向嘴边，张嘴咀嚼，碎屑/爱心，满足表情；
  - 摸摸：靠近镜头、眯眼、蹭手、爱心；
  - 玩耍：跳跃/转圈、球弹跳、尾巴摇；
  - 睡觉：趴下、闭眼、Zzz、呼吸；
  - 整理：泡泡/闪光。
- 交互：拖拽旋转、点击伙伴摸摸、按钮触发动作；动作期间防重复；无 WebGL 时回退 2D SVG。
- 性能：dpr≤2，单 canvas，页面离开 dispose。
