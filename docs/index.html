快速开始

需要 Node.js 24+。运行时零 npm 依赖，SQLite 自动建库与迁移。

./scripts/start.sh          # 安全默认：首次打开创建管理员
./scripts/start.sh --demo   # 演示数据（仅限本机）
docker compose up -d        # 生产式单容器
npx tsc --noEmit && npm test

演示模式账号（仅 --demo / 演示 Compose）：

家长parent@demo.com · Parent123!
教师（可审核）teacher@demo.com · Teacher123!
管理员admin@demo.com · Admin123!

生产部署请保持 DEMO_MODE=false、SEED_DEMO=false，启用 HTTPS，并配置连接器允许域名。详见 产品文档 · 权限与隐私 与 README 的生产清单。
