# 星芽伙伴 · 宠物陪伴、奖励与 UI/UX 升级设计（v1.2）

## 1. 目标
让「学习」变成孩子主动期待的事：每次完成都有即时、具体、可积累的正反馈；一只会饿、会开心、会记住孩子的伙伴，把课程、计划、奖励串成一条成长线。同时把家长端从「工具感」提升为温暖、精致、有呼吸感的成长空间。

## 2. 对标与取舍
| 对标 | 借鉴 | 取舍 |
|---|---|---|
| Duolingo | 连续学习、宝石、角色情绪 | 不做排行榜/同伴压力；奖励只与「自己今天做到了」比较 |
| 斑马 / 小猴 | 卡通伙伴、即时音效与动画 | 伙伴不打断学习流程，只在关键节点出现 |
| Finch / 电子宠物 | 照顾行为与情感连接 | 饥饿/心情衰减温和，不制造愧疚；无惩罚性死亡 |
| Seesaw | 家庭成长记录 | 宠物与真实课程/计划绑定，不做纯养成 |
| 星芽现有 | 计划、课程、报告 | 所有奖励来自真实完成，不凭空刷分 |

## 3. 伙伴模型
- 三种可领养伙伴：**团子兔**（温柔）、**小橘狐**（好奇）、**芽芽龙**（活力）。每个孩子一只，可改名（一次免费，后续用金币）。
- 属性：饱食度、心情、精力、羁绊值、等级、经验；随时间**温和**衰减：单次离线最多损失 18/14/12 点，饱食/心情/精力下限 35/38/30；≥24h 进入「有点想你」，不会死亡、不会生病。
- 情绪：`happy / excited / hungry / sleepy / sad`，由属性与最近互动推导；表情、台词、动画随情绪变化。
- 互动：喂食（消耗食物）、玩耍（有冷却，消耗精力）、摸摸（短冷却）、睡觉（恢复精力）、清洁（提升心情）。动作有即时动画、爱心/气泡和一句儿童能听懂的话。
- 学习联动：完成课时 +经验/心情；低分会得到安慰而不是责备；连续完成/章节完成/计划完成有更大仪式。

## 4. 奖励体系
| 来源 | 规则（首通才发币，避免刷分） |
|---|---|
| 课时完成 | 星星 1–3（按服务端判分），金币 10 + floor(得分/10)（0–100 分对应 10–20 枚），经验 10；重复完成只给宠物心情反馈，不再发币 |
| 单元完成 | 一次性 +30 金币、+25 经验、单元徽章 |
| 计划完成 | 一次性 +100 金币、+60 经验、伙伴限定配饰、专属庆祝证书 |
| 每日 | 完成今日计划/喂食/玩耍，伙伴台词与「今日小星星」 |
- 金币用途：宠物小铺购买食物、衣服、玩具、房间装饰；衣服可穿脱；食物可投喂。
- 防刷：`reward_events(child_id, source_type, source_id)` 唯一；API 幂等；重学不发币。
- 伦理：不惩罚、不排名、不制造「宠物会死」的焦虑；低分文案为「再试一次就好」。

## 5. 关键界面
- **首页**：晨光背景 + 今日冒险卡 + 伙伴小窝卡（情绪/台词/快捷喂食/玩耍）+ 今日任务清单 + 学习节奏 + 成长里程碑。
- **伙伴页**：房间场景（窗、地毯、玩具）、大尺寸 SVG 伙伴、情绪气泡、四条状态、互动按钮、小铺/衣橱/背包标签页。
- **课时完成**：全屏庆祝层（彩纸、星星、伙伴跳舞、金币/经验/星星、正确率、下一课）；单元/计划完成使用更高规格 + 证书。
- **全站视觉**：奶油纸张 + 极光渐变 + 星点/叶片装饰 + 毛玻璃卡片 + 衬线大标题；桌面顶栏展示金币与伙伴心情，移动端通过首页伙伴卡、顶栏心情与菜单进入；底部保持 5 个入口，不新增第 6 个。

## 6. 数据与 API
新增表：`pets, wallets, shop_items, pet_inventory, reward_events, pet_interactions`。迁移 v4，幂等。
- `GET /api/pet?childId` 状态、钱包、背包、商店、任务
- `POST /api/pet/adopt`、`/interact`、`/shop/buy`、`/equip`
- 课时/设备完成响应增加 `rewards`（coins/exp/stars/milestones/pet reaction）；`PATCH plan item` 完成返回计划里程碑。
- 所有家庭/孩子隔离、金额服务端计算、互动限流。

## 7. 验收要点
1. 新孩子可领养三种伙伴之一；属性衰减与情绪正确。
2. 完成课时首通发币，重复不发；答题分数影响星星与金币。
3. 单元/计划完成只发一次，并出现庆祝 + 证书/配饰。
4. 小铺购买、喂食、穿衣生效且余额/背包正确；金币不足 422。
5. 家长/孩子隔离：不能操作别人家宠物。
6. 首页/伙伴页/庆祝在手机与桌面均无横向滚动；伙伴动画不阻塞学习。
7. 旧课程、计划、设备、社区流程不回归。

## 8. v1.3 评审后修订（Reviewer #5）

- **不做愧疚引擎**：离线衰减封顶（最多损失 18/14/12 点），属性下限 35/38/30；离开 ≥24h 显示「有点想你」而非饥饿指责。基础小饼干**免费无限**；金币只用于装扮、玩具、房间小物和额外口味，不参与基础照顾。
- **奖励不受客户端控制**：课时得分由服务端根据 `answers` 与题目答案计算；客户端 `score` 仅做范围校验，不再用于发币；无答题时按中性 80 分。计划金币要求 **≥3 个项目且跨 ≥3 天**，只在首次完成发放；小计划仍显示完成但无金币。
- **儿童向不显示分数**：庆祝层展示星星、金币、经验与「答对 X/Y 题」，不展示数字分数；分数留在家长看板。
- **仪式分级**：课时用庆祝层；单元/计划在同一层展示里程碑与证书；一次学习只出现一个全屏层；支持 `prefers-reduced-motion`，跳过彩纸动画。
- **导航不加第 6 个底部入口**：桌面侧栏新增「我的伙伴」；移动端通过首页伙伴卡、顶栏心情 chip 和菜单进入。
- **可访问性**：庆祝层焦点陷阱、Esc 关闭、关闭后焦点归还；按钮有 aria-label；关键信息不只依赖颜色。
- **宠物数据治理**：名字经过社区同一套规范化与违禁检测；宠物/钱包/背包/奖励计入孩子数据导出；删除孩子或家庭时级联删除；购买 ≥60 金币有确认。
- **验收补充**：48h 缺席温暖状态、客户端伪造分数、单项目/短计划刷币、重复购买、键盘焦点、reduced motion、320px / 横屏、宠物关闭后基础学习不受影响。
- **边界**：宠物是虚拟陪伴，不涉及真实商品物流；不做排行榜；不因缺席死亡或降低学习权限。
